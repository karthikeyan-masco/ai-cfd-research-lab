# Roadmap

## Milestone 1 — debate engine (current)
- Four role prompts and wrappers
- Bounded debate protocol
- Offline demo provider
- Optional OpenAI-compatible adapter
- Normal shock, oblique shock and Sod exact benchmarks
- Unit tests and Streamlit demonstration UI

## Milestone 2 — reliable evidence ingestion
- PDF parsing and metadata extraction
- Citation-aware retrieval
- Curated compressible-flow reference library
- Claim-to-source traceability

## Milestone 3 — computational tools
- Read-only OpenFOAM case inspector
- Python calculation sandbox
- Structured simulation specification
- Human approval gate
- Isolated execution worker

## Milestone 4 — CFD validation
- Sod numerical solver comparison
- Normal/oblique shock benchmarks
- Flat-plate compressible boundary layer
- Compression-ramp SWBLI
- Mesh and time-step studies

## Milestone 5 — persistent research projects
- Project database
- Reproducibility manifests
- Experiment tracking
- Debate and evidence history
- Research dashboard

## Not in current milestone
- Autonomous arbitrary shell access
- Unattended OpenFOAM case modification
- Claims of autonomous scientific discovery
- Combustion/plasma/FSI multiphysics
